OSINT::CONSOLE

Реальные API-запросы с телефона • без серверов • без трекинга
API: ipwho.is — страна, город, координаты, ASN, провайдер. Кнопки открывают внешние сервисы.
Реальные resolve через DNS-over-HTTPS (dns.google). Брутфорс проверяет ~80 типовых префиксов: dev, vpn, mail, api, git, jira...
GitHub API: имя, email, локация, компания, репо, звёзды — всё честно через публичный API.
Разбор: страна, тип линии (моб/фикс), формат E.164 — полностью оффлайн (libphonenumber).
EXIF-чтение в приложении (exifr): камера, дата, ISO, GPS-координаты с переходом на карту.
Кнопки строят готовые Google-запросы: Telegram, VK, соцсети, дампы, документы.
