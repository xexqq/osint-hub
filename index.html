Что внутри

  • Умный поиск — вводите что угодно: email, телефон, IP, домен, ник, имя. Приложение само определяет тип и запускает все релевантные проверки.
  • IP-интел — страна, город, координаты, ASN, провайдер + обратное DNS (rDNS) через DNS-over-HTTPS.
  • Домены — все DNS-записи (A/AAAA/MX/NS/SOA/TXT/CNAME), брутфорс поддоменов (реальные резолвы, списки до 230 префиксов), RDAP WHOIS, ссылка crt.sh / Wayback / urlscan.
  • Email — разбор, провайдер, MX-проверка, Gravatar-профили по md5(email).
  • Телефоны — оффлайн-разбор через libphonenumber: валидность, страна, тип линии, E.164.
  • Фото — EXIF-чтение в приложении через exifr: камера, дата, ISO, диафрагма, GPS + прямые ссылки Google Maps / OSM / Яндекс.Карты (спутник).
  • Никнеймы — GitHub-разведка (имя, email, локация, репо, компания) + прямые ссылки профилей на 20 платформах + WhatsMyName (600+ сайтов).
  • Dork-конструктор — собирает сложный запрос из чипов-модификаторов (site:, filetype:, "index of") и открывает в вашем поисковике.
  • История — последние 50 запросов хранятся локально, экспорт в буфер.
  • Настройки — тема (тёмная/светлая), страна по умолчанию, размер списка поддоменов, поисковики, интервал открытий.
  • Диагностика — встроенная самопроверка: DoH, ipwho.is, GitHub API, CDN-библиотеки.

Приватность

  • Никаких серверов, аккаунтов и трекинга. У приложения нет своего backend.
  • Запросы идут напрямую к публичным API (github.com, ipwho.is, dns.google) с устройства.
  • История и настройки — только на вашем телефоне (device storage).
  • Оффлайн-функции: разбор телефонов, разбор email, чтение EXIF — работают без интернета.
Важно. Используйте только легально: свои данные, свои аккаунты, authorized security-исследования. То, что приложение умеет делать запросы к публичным API, не снимает ответственности: работайте только со своими данными или в рамках закона (authorized исследования, security research).
